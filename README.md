# Apex Computer Institute - MERN Stack Website & Management System

ਇਹ ਇੱਕ ਪੂਰਾ **MERN Stack** (MongoDB, Express.js, React, Node.js) ਵੈੱਬ ਐਪਲੀਕੇਸ਼ਨ ਹੈ ਜੋ ਖਾਸ ਤੌਰ 'ਤੇ ਕੰਪਿਊਟਰ ਟਰੇਨਿੰਗ ਇੰਸਟੀਚਿਊਟ ਲਈ ਡਿਜ਼ਾਈਨ ਕੀਤਾ ਗਿਆ ਹੈ।

---

## ✨ ਮੁੱਖ ਫੀਚਰ (Key Features)

1. **Courses Catalog (ਕੋਰਸਾਂ ਦੀ ਸੂਚੀ)**
   - DCA, ADCA, Tally Prime + GST, Web Development (MERN), Python + AI, Graphic Designing.
   - ਕੋਰਸਾਂ ਦੀ ਪੂਰੀ ਸਿਲੇਬਸ ਡਿਟੇਲ, ਫੀਸ ਅਤੇ ਮਿਆਦ।
   - ਕੈਟੇਗਰੀ ਅਤੇ ਸਰਚ ਫਿਲਟਰ।

2. **Online Student Admission Form (ਆਨਲਾਈਨ ਦਾਖਲਾ ਫਾਰਮ)**
   - ਵਿਦਿਆਰਥੀ ਆਪਣਾ ਨਾਂ, ਪਿਤਾ ਦਾ ਨਾਂ, ਫੋਨ, ਪੜ੍ਹਾਈ ਅਤੇ ਕੋਰਸ ਚੁਣ ਕੇ ਆਨਲਾਈਨ ਦਾਖਲਾ ਅਪਲਾਈ ਕਰ ਸਕਦੇ ਹਨ।
   - ਆਟੋਮੈਟਿਕ ਐਪਲੀਕੇਸ਼ਨ ਆਈਡੀ (ਜਿਵੇਂ `APP-2026-101`) ਜਨਰੇਟ ਹੁੰਦੀ ਹੈ ਅਤੇ ਰਸੀਦ ਪ੍ਰਿੰਟ ਕੀਤੀ ਜਾ ਸਕਦੀ ਹੈ।

3. **Student Certificate Verification Portal (ਸਰਟੀਫਿਕੇਟ ਵੈਰੀਫਿਕੇਸ਼ਨ ਪੋਰਟਲ)**
   - ਸਰਟੀਫਿਕੇਟ ਨੰਬਰ (ਜਿਵੇਂ `APEX-2026-001`) ਜਾਂ ਰੋਲ ਨੰਬਰ (ਜਿਵੇਂ `202601`) ਪਾ ਕੇ ਆਨਲਾਈਨ ਜਾਂਚ।
   - ਅਧਿਕਾਰਤ ਸਰਟੀਫਿਕੇਟ ਕਾਰਡ, ਗ੍ਰੇਡ, ਨੰਬਰ, ਅਤੇ ਡਾਇਰੈਕਟਰ ਸੀਲ ਨਾਲ ਪ੍ਰਿੰਟ/ਸੇਵ ਕਰਨ ਦੀ ਸੁਵਿਧਾ।

4. **Campus Gallery & Contact Us**
   - ਲੈਬਾਂ, ਕਲਾਸਰੂਮਾਂ ਅਤੇ ਸਰਟੀਫਿਕੇਟ ਵੰਡ ਸਮਾਗਮਾਂ ਦੀ ਗੈਲਰੀ।
   - ਆਨਲਾਈਨ ਪੁੱਛਗਿੱਛ (Inquiry) ਫਾਰਮ, ਫੋਨ, ਈਮੇਲ ਅਤੇ ਪਤਾ।

5. **Admin Management Dashboard (ਐਡਮਿਨ ਪੈਨਲ)**
   - ਸੁਰੱਖਿਅਤ ਲੌਗਇਨ: `admin@institute.com` / `admin123`
   - ਨਵੇਂ ਸਰਟੀਫਿਕੇਟ ਜਾਰੀ ਕਰਨਾ (Issue Certificate)
   - ਦਾਖਲੇ ਪ੍ਰਵਾਨ/ਰੱਦ ਕਰਨਾ (Approve / Reject Admissions)
   - ਕੋਰਸ ਜੋੜਨਾ ਜਾਂ ਡਿਲੀਟ ਕਰਨਾ (Add / Edit Courses)
   - ਵਿਦਿਆਰਥੀਆਂ ਦੇ ਸੁਨੇਹੇ ਵੇਖਣਾ (Inquiries)

## 🗄️ Database ਬਾਰੇ ਜਾਣਕਾਰੀ

- **Zero-Setup Mode**: ਜੇਕਰ ਤੁਹਾਡੇ ਕੰਪਿਊਟਰ ਵਿੱਚ MongoDB ਇੰਸਟਾਲ ਨਹੀਂ ਹੈ, ਤਾਂ ਵੀ ਇਹ ਐਪਲੀਕੇਸ਼ਨ ਬਿਨਾਂ ਕਿਸੇ ਐਰਰ ਦੇ ਆਟੋਮੈਟਿਕ Local JSON Store (`backend/data/store.json`) ਵਿੱਚ ਸਾਰਾ ਡਾਟਾ ਸੇਵ ਰੱਖਦੀ ਹੈ।
- **MongoDB Atlas / Local**: ਜੇਕਰ ਤੁਸੀਂ MongoDB ਨਾਲ ਕਨੈਕਟ ਕਰਨਾ ਚਾਹੁੰਦੇ ਹੋ, ਤਾਂ `backend/.env` ਫਾਈਲ ਵਿੱਚ ਆਪਣਾ MongoDB ਕਨੈਕਸ਼ਨ ਸਟਰਿੰਗ ਪਾਓ:
  ```env
  MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/institute_db
  ```
